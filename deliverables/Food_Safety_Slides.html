The problem

Which places fail food inspections, and can we predict it?

  • Chicago checks every restaurant, shop and school that serves food
  • Each check ends in Pass, Pass with conditions or Fail
  • The city publishes every result. We used 2022 – 2025
  • Our job: clean the data, store it well, answer 10 questions, and try to predict failures

Our approach

The whole project in one picture

  • Clean the data
  • Store it in a database built for questions (a data warehouse)
  • Ask the 10 questions and show the answers on a dashboard
  • Predict with 3 simple models
  • Copy the same data into 2 other kinds of storage and compare
Step 1 · Cleaning the data

Find every problem, fix it, write it down

  • Some rows were visits that never happened (shop closed, no entry): kept, but not counted
  • 29 reports entered twice: removed
  • 217 spellings of shop type → 7 groups
  • Violations were one long sentence: we counted them
  • Result: 73,630 rows → 61,737 real inspections
Step 2 · The database design

A star: one main table, five lookup tables

  • Main table: one row per inspection, only numbers
  • Lookup tables: when, which place, why, result, where
  • Simple and fast to ask questions
  • A second main table: one row per place per year
Step 3 · Loading the data

Load it, then check nothing went wrong

  • The clean file goes into a waiting table first
  • One program moves it into the database
  • First load: 2022 – Nov 2025 (60,608)
  • Then only December 2025 (1,129), no reload
  • 5 checks after each load: all OK

Step 5 · Prediction 1

How many problems will an inspection find?

  • Learn from 2022 – 2024, test on 2025
  • Most useful clue: the place's last inspection
  • Our guess is off by 2.45 problems on average
  • A plain average guess is off by 2.71
  • Hard to predict: the real causes (cleanliness, staff) are not in the data
Step 5 · Patterns

What usually happens together?

  • We looked for things that often appear together
  • 10 or more problems → Fail, 69% of the time
  • That is 3 times more often than normal
  • Low-risk places are mostly grocery stores
Step 5 · Prediction 2

Will this inspection fail?

  • A decision tree: a list of yes / no questions
  • Strongest clue: did the last inspection fail?
  • It catches 6 in 10 failing places
  • Useful to decide which places to inspect first
Step 6 · Database on 3 machines

Same data, split across computers

  • One main computer takes the question
  • Two helper computers each hold half of the data
  • All 25 test questions gave the same answers
  • Slower with small data, faster with big data
Step 7 · Live dashboard

Inspections shown as they arrive

  • We replay late 2025 as if it were happening now
  • Each inspection is sent as a message
  • It is checked, stored and shown in about 2 seconds
  • All 24 broken test messages were caught
